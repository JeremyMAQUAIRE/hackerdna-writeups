## 🎯 Objectif du laboratoire

Ce laboratoire permet de découvrir le fonctionnement de la plateforme HackerDNA et de se familiariser avec les premières étapes de résolution d'un défi.

L'objectif est de comprendre les consignes, d'explorer l'environnement proposé et d'adopter une démarche méthodique.

---

## 🛠️ Outils utilisés

- Navigateur web
- Plateforme HackerDNA
- Observation et analyse des informations affichées
