# Learn 101

**Lab :** [Learn 101 sur HackerDNA](https://hackerdna.com/labs/learn-101)  
**Niveau :** Initiation

## Mon premier lab

J'ai commencé par **Learn 101** pour découvrir comment fonctionnent les exercices sur HackerDNA.

Le principe est assez simple : on lance le lab, on regarde ce qui est demandé, puis on avance à partir des éléments affichés. C'était surtout l'occasion de prendre mes repères sur la plateforme avant de passer à des exercices plus orientés sécurité web.

## Ce que j'en retiens

Ce premier exercice m'a surtout servi à comprendre le déroulement d'un lab : lire l'énoncé, observer ce qui est disponible et vérifier le résultat.

Ce n'est pas le lab le plus technique du dépôt, mais il m'a permis de commencer sur de bonnes bases.

Je ne publie pas la réponse ni le flag : le mieux reste de faire l'exercice soi-même.
